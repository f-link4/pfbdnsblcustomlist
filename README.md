# pfbdnsblcustomlist

Custom DNSBL blocklist.

Format: one domain per line, `#` for comments, `*.domain.tld` for wildcard subdomains.

## ⚠️ Scope — this is a supplement, not a full blocklist

**This list does not claim to be comprehensive or complete.**

It is meant to be used **as a supplement to other blocklists** (StevenBlack, EasyList, EasyPrivacy, AdGuard DNS, Hagezi, OISD, etc.), **not as a replacement**.

It contains a small, hand-picked set of domains that:

- were **missed by the major public feeds** at the time of writing, or
- are **specific to the author's environment** and not covered by general-purpose lists.

If you are looking for a **full** DNS blocklist, use established public feeds first. Add this list **on top** of them, not instead of them.

## What's inside

The list contains domains in the following categories:

- **Tracking / Analytics** — telemetry, analytics, session recording
- **Ads** — ad networks and trackers
- **Consent / CMP** — cookie banners and consent management platforms
- **Scam / Redirect** — known scam domains and redirectors
- **Telemetry** — OS and application telemetry (Microsoft, Huawei, Yandex, etc.)
